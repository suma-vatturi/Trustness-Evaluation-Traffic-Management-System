# Dataset Download Instructions

The dataset used in this project is hosted on Roboflow. Follow these steps to download the dataset:

1. Visit the dataset page: [Street View Dataset](https://app.roboflow.com/sumavatturi/street-view-gdogo-a7du4/1)

2. To download the dataset, you will need to:
   - Create a Roboflow account if you don't have one
   - Log in to your Roboflow account
   - Access the dataset through the provided link
   - Choose your preferred export format (recommended: YOLO v8)

3. Once you have access, you can:
   - Download the dataset directly through the web interface
   - Or use the Roboflow API to programmatically download the dataset

4. The dataset will include:
   - Training images
   - Validation images
   - Test images
   - Corresponding annotation files

Note: Make sure to place the downloaded dataset files in this directory while maintaining the original folder structure for proper integration with the training pipeline.
